# 英语启蒙乐园

给小孩看本地英语启蒙视频的网页，部署在飞牛OS（NAS）上，iPad / 安卓平板 / 电脑浏览器访问。
每天 20 分钟：看视频 8 分钟 → 跟读单词 5 分钟（10 个词）→ 看图连词 5 分钟 → 学习总结 2 分钟。

端口 **13002**，只在局域网使用，不要在路由器上做端口映射。

---

## 一、部署（飞牛OS）

镜像由 GitHub Actions 自动构建（每次 push 到 `main`），推到 `ghcr.io/blackanubis/englishvideo:latest`，
支持 `linux/amd64` 与 `linux/arm64`。NAS 上只需一个 compose 文件，不用传源码。

### 方式 A：拉镜像（推荐）

1. 先确认镜像包是公开的（只需一次）：
   GitHub 仓库 → **Packages** → 点 `englishvideo` → **Package settings** → 把 Visibility 改成 **Public**
   （不想公开的话，就在 NAS 上执行 `docker login ghcr.io`，填你的 GitHub 账号 + PAT）
2. 把 `docker-compose.yml` 单独传到 NAS，例如 `/vol3/1000/project/english-kids/docker-compose.yml`
3. 改挂载路径：

```yaml
      - /vol1/1000:/media/root:ro      # 改成你放视频的那一级目录（只读）
      - ./data:/app/data               # 学习记录、配置、截图，不要动
```

4. 启动：

```bash
cd /vol3/1000/project/english-kids
docker compose up -d
docker compose logs -f        # 看到 "英语启蒙服务已启动" 即可
```

5. 浏览器打开 `http://<NAS的IP>:13002`

> 以后代码更新了，NAS 上执行 `docker compose pull && docker compose up -d` 即可升级。

### 方式 B：源码本地构建

把整个仓库 zip 上传到 NAS（Actions 每次运行也会在 Artifacts 里附一份源码包），解压后：

```bash
cd /vol3/1000/project/english-kids
docker compose up -d --build
```

此时需要在 `docker-compose.yml` 里注释 `image:` 那行、放开 `build: .` 两行。

## 二、第一次使用

1. 右上角 **⚙️** → **📂 选择视频目录**
2. 在弹出的目录列表里一层层点进去，找到放动画的文件夹
   （每层右边会显示"这层下面有多少个视频"，方便确认找对了）
3. 点 **就用这个目录** → 自动开始扫描
4. 回到底部 **📺 看视频**，就能看到带封面的视频列表了

> 视频目录存在 `data/config.json`，以后换目录或加目录都在网页里改，不用碰 compose 文件。

## 三、iPad 加到桌面（像 App 一样打开）

Safari 打开 `http://<NAS的IP>:13002` → 底部分享按钮 → **添加到主屏幕**。
之后点桌面图标就是全屏打开，没有地址栏。

## 四、四个功能怎么用

| 页面 | 孩子做什么 | 说明 |
|---|---|---|
| 🏠 今日 | 点"开始学习"，按顺序走完四项 | 顶部圆环是今日进度 |
| 📺 看视频 | 点封面选集，可以全屏 | 只统计真正在播的时间；看完自动跳下一集 |
| 🗣️ 跟读 | 点 🔊 听发音 → 跟读 → 点 ✅ 我读过了 | 读完 10 个词自动提示去下一项 |
| 🧩 连词 | 先点一张图，再点右边的单词 | 连对了有绿线；可以"换一组" |
| 🏆 总结 | 看今天学了多少、连续几天 | 进这个页面即视为当日打卡 |

## 五、视频要求（重要）

- **必须是 mp4（H.264 + AAC）**。mkv / avi / rmvb / webm 在 iPad 上播不了，
  家长设置页的"自检"会列出播不了的文件，用 HandBrake（Fast 1080p30 预设）转成 mp4
- **命名带序号**，保证播放顺序：`001-Alphabet Song.mp4`、`002-Old MacDonald.mp4`
  网页会自动把文件名变成标题（`001-Alphabet Song.mp4` → `Alphabet Song`）
- 单集 3～5 分钟最合适

## 六、图词标注（可选，但很推荐）

视频扫描时会自动抽帧（默认每 15 秒一张，可在设置里改间隔）。
家长设置 → **开始标注** → 选一个视频 → 点某张截图 → 选它对应的单词。
标过的图会进入"看图连词"游戏，孩子看到的是动画里的真实画面。
**没标过的词自动用彩色图标**，不影响使用，可以慢慢补。

## 七、从视频里提取单词（字幕 / 语音识别）

家长设置 → **🎙️ 从视频里提取单词** → 开始提取 → 提取完点 **查看候选词** → 勾选 → 导入。
导入后这些词立刻进入「跟读单词」和「看图连词」。

**处理顺序（自动的，不用你选）**

1. **外挂字幕**：视频同目录的 `xxx.srt / .vtt / .ass`
2. **内嵌字幕**：视频文件里的字幕流（飞牛影视能显示字幕不代表文件里真有字幕——
   它有可能是在线刮削的，那条路我们拿不到，只能走第 3 步）
3. **语音识别**：ffmpeg 抽音轨 → Whisper（base 模型）转写，带词级时间戳

**候选词表里每一列**

| 列 | 说明 |
|---|---|
| 勾选框 | 已在词库里的词会置灰，不会重复导入 |
| 中文 | 自动从内置词典补（4000 条），没命中就留空，你手填 |
| 分类 | 动物/水果/颜色等自动推断，推断不出归到 `video` |
| N 集 / N 次 | 出现集数越多越"核心"，默认按这个排序 |
| 配图 | 勾了就在**说出这个词的那一刻**截一帧，自动成为连词的配图 |
| 样例句 | 方便你判断这个词是不是识别错了 |

**几个要注意的**

- 儿歌是唱的，识别会有错词和重复歌词，**所以是勾选制不是全自动**
- 转写结果会顺手写成字幕，播放页的 CC 里能开
- 清空提取结果只删字幕/转写缓存，不影响词库和学习记录

### 快速模式（推荐一直开着）

勾上 **快速模式**，每集只识别前 60～180 秒（网页里可选）。儿歌的词汇重复度极高，
开场一两分钟基本能拿到全部生词，整体快 3～5 倍。

代价是**不生成完整字幕**——快速模式只服务"提取单词"这一个目的。
要完整字幕就取消勾选，让它全片转写。

### 关于 GPU（先看这里再折腾）

**Whisper 语音识别只认 NVIDIA 独显（CUDA）**，Intel UHD / Iris / AMD 核显一律不支持，
这是底层推理库 CTranslate2 的限制，不是配置问题。飞牛这类 NAS 基本都是 Intel 核显，
所以识别只能跑 CPU——别在这一步上浪费时间。

程序会自己判断：检测到 CUDA 就走 GPU（float16），否则走 CPU（int8 + 多线程）。
设置页的「自检」会明确写出当前用的是哪个引擎。

CPU 侧能做的提速就三件事，都已经默认开了：

| 手段 | 效果 |
|---|---|
| 多线程（`EK_WHISPER_THREADS`，默认取最多 8 核） | 2～4 倍 |
| 快速模式（只听前 90～180 秒） | 3～5 倍 |
| int8 量化 | 约 2 倍 |

如果你确实有 NVIDIA 独显并想启用，需要用 `Dockerfile.gpu` 自行构建
（CUDA 运行时约 3GB，所以主镜像默认不带），再解开 `docker-compose.yml` 里
`deploy.resources.reservations.devices` 那几行注释，并把 `EK_WHISPER_DEVICE` 设为 `auto`。

> 顺带一提：**Intel 核显在「视频转码」上是有用的**（QSV 硬件编码）。
> 自检页会显示是否识别到 `/dev/dri` 和 `h264_qsv`——那属于 mkv/avi 转 mp4 的场景，
> 跟语音识别是两回事。

## 八、常见问题

**Q：iPad 上没有"录一遍"按钮？**
局域网 http 下 Safari 禁止使用麦克风，这是浏览器限制。
跟读用 ✅ 我读过了 打卡即可；想真录音需要在 NAS 上配 HTTPS。

**Q：点 🔊 没有声音？**
朗读用的是设备自带的英文语音，跟 NAS 无关。
iPad：设置 → 辅助功能 → 朗读内容 → 声音 → 英语，下载一个语音。
Windows：设置 → 时间和语言 → 语音 → 添加英语语音。

**Q：视频封面是灰色的？**
容器里没装到 ffmpeg 或视频还没抽帧。家长设置页"自检"会显示 ffmpeg 是否可用；
可用就点一次 **重新扫描并生成截图**，等进度跑完。

**Q：学习记录存在哪？**
`english-kids/data/progress.json`，备份直接拷这个文件。
换设备、清浏览器缓存都不会丢。家长设置页可以导出 JSON。

**Q：想改词库？**
编辑 `data/words.csv`（首次启动从 `defaults/words.csv` 复制）。
列：`word,zh,category,emoji,sentence`，category 就是家长设置里的主题。
改完不用重启，家长设置页重新勾选主题即生效。

**Q：想改每天学多久？**
家长设置 → 每日安排，改完点保存。

## 九、目录结构

```
english-kids/
├── .github/workflows/build.yml   CI：push 到 main 自动构建并推送 GHCR 镜像
├── Dockerfile              python:3.12-slim + ffmpeg + faster-whisper（模型在构建时烤进镜像）
├── docker-compose.yml      端口 13002，媒体根只读挂载
├── server.py               后端（Python 标准库，语音识别为可选依赖）
├── asr.py                  字幕解析 / 语音转写 / 候选词聚合
├── defaults/words.csv      默认词库（78 个词，8 个主题）
├── defaults/dict-en-zh.csv 内置英中词典（4000 条，给候选词自动补中文）
├── web/                    前端页面
└── data/                   运行时生成（配置、记录、截图，已挂到数据卷）
    ├── config.json
    ├── library.json
    ├── progress.json
    ├── annotations.json
    ├── asr/                提取结果：transcripts/ 转写文本、subs/ 生成的字幕
    └── thumbs/             截图（含 asr/ 自动配图）
```
